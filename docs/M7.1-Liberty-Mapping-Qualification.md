## 3. Separate source acquisition and local preflight

Do not use random internet `.lib` files. Clone the corresponding official source / documented platform into **outside the MSIF repository**, inspect its license, and pin a commit. Example reconnaissance (clone size may be significant):

```bash
mkdir -p "$HOME/eda/qualified-pdks"
git clone --depth 1 https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts.git   "$HOME/eda/qualified-pdks/OpenROAD-flow-scripts"
cd "$HOME/eda/qualified-pdks/OpenROAD-flow-scripts"
git rev-parse HEAD
find flow/platforms/sky130hd -type f   \( -name '*.lib' -o -name '*.lib.gz' -o -name '*.lef' -o -iname '*license*' \) | sort | head -100
```

The repo may reference external platform downloads/submodules; do **not** assume `git clone` gives you the complete PDK. Follow the official `flow/` setup README for the selected release, then locate the actual installed Liberty. Use `find` to identify the path, *not* a guessed filename. If the found Liberty is gzipped, decompress **outside** MSIF before using `--liberty`, preserving original hashes.

```bash
# Set only after manual inspection; path must be absolute and have no whitespace
export MSIF_LIB=/absolute/path/to/reviewed-sky130hd-tt.lib
test -s "$MSIF_LIB" || exit 1
realpath "$MSIF_LIB"
sha256sum "$MSIF_LIB"
file "$MSIF_LIB"
grep -m 1 -E '^[[:space:]]*library[[:space:]]*\(' "$MSIF_LIB"
yosys -Q -T -p "read_liberty -lib $MSIF_LIB; stat" > /tmp/msif-liberty-preflight.log 2>&1 || {
  cat /tmp/msif-liberty-preflight.log; exit 1;
}
```

The parser check is necessary but insufficient: examine library definitions, PVT, units, license, sequential mapping and timing data manually. Existing `m71_compare.py` rejects Liberty paths containing spaces or Yosys control characters; use an uncomplicated absolute path.

## 5. Independent mapped-netlist review (mandatory before LQ)

The existing M7.1 verifier requires zero Yosys `check` problems and a final `Number of cells` line, but that **does not prove all flip-flops and combinational cells map into the Liberty**. In particular, async-reset FF structures may be unmappable to a chosen library. Validate all three logs and inspect residual `$_*` / `$*` cells. Run an independent Yosys mapping report and `stat -liberty` for each architecture before reporting a cell-area sum. Record actual area only when reported by the installed tool, and label it `Liberty cell-area estimate`, never placed/routed die area.

```bash
for v in programmable fixed rom; do
  echo "===== $v ====="
  grep -F 'Found and reported 0 problems.' "build/m71_liberty/m71_${v}.log" || exit 1
  grep -E 'Number of cells:|Chip area|ABC RESULTS|unmapped'     "build/m71_liberty/m71_${v}.log" | tail -30
  if grep -Ei 'ERROR:|FATAL:|%Error|%Warning' "build/m71_liberty/m71_${v}.log"; then
     echo "Tool diagnostic in $v"; exit 1
  fi
done
```

Additional **required engineering improvements to the current runner before claiming M7.1-LQ**: emit a mapped Verilog netlist per variant; import the Liberty into the mapped design and run strict cell-type inventory; reject unsupported generic cells / blackboxes unless explicitly documented; record total cell area from Liberty mapping, mapping constraints and ABC settings; distinguish combinational vs sequential cells and inferred memory. Re-run gate-level numerical equivalence and reset/valid regression against each mapped netlist. `stat -liberty` alone is not a timing signoff; standard-cell timing requires constraints, path analysis, and appropriate clock assumptions.

## 6. Timing/PPA experiment ladder

1. **M7.1-L discovery:** one reviewed Liberty, all three variants, identical Yosys settings, cell counts; no area/frequency claim.

3. **M7.2 floorplan/STA:** obtain matching LEF, tech LEF, corners and RC tech files, establish SDC `create_clock`, input/output delays, loads, false/multicycle path review. Do not guess physical values.
4. **M7.2 placed/CTS/routed:** use OpenROAD Flow Scripts for a supported PDK; retain config.mk, SDC, LEF/Liberty, route, congestion, timing, power assumptions and extraction metrics; compare A/B/C under identical constraints.
5. **Memory fairness:** replace inferred arrays with appropriately characterized hard SRAM/ROM macros or explicitly report cell-based memory costs; account for decoder and interface area.
6. **G1 governance:** EvidenceLedger + bounded command execution + reviewer-approved signed manifest + provenance + Node2 validation receipt. A self-signed manifest cannot approve itself.
