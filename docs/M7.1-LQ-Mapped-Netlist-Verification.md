## Contract and scientific limits

Preserve the existing 2×4 signed INT4/INT8/INT32 GEMV contract and the original [architecture](MSIF-Source-Specification.md). The [M7.1 experiment](M7.1-Liberty-Mapping-Qualification.md) proves exploratory mapping only. This LQ candidate adds export of each mapped Verilog netlist and Yosys JSON, a cell inventory constrained to the selected Liberty catalog, and **bounded mapped gate-level simulation** with the existing deterministic reference vectors. The script does **not** implement unbounded equivalence or a universal sequential formal proof; those remain explicit outstanding acceptance gates.

The mapped-RTL behavioral comparison uses `create_testbench` and the independent Python numerical oracle. It validates cycle-valid behavior and the numeric outputs over 260 vectors per architecture (four corner patterns plus 256 seeded vectors). The current testbench covers initial reset and valid deassertion but does **not** comprehensively exercise midstream asynchronous reset, backpressure or arbitrary state trajectories. Therefore distinguish **bounded regression PASS** from **sequential formal equivalence PENDING**.

## Node1 incident correction: mapped-cell model coverage (26 October 2026)

`build/m71_liberty/m71_*.log` ABC mappings. After LQ's revised mapping sequence
(`read_liberty -lib` precedes synthesis), the actual exported `msif_programmable_mapped.v`
uses extra cell types absent from that bundle: `a21boi_0`, `a311oi_1`, `a31o_1`,
`o2111ai_1`. Consequently `iverilog` returned an unknown-module error before
simulation. A Liberty cell inventory PASS establishes membership in the Liberty,
not availability of the matching Verilog functional module.

The LQ runner now requires `SKY130_HD` pointing to the vetted upstream source
checkout and assembles an **exact functional simulation bundle per mapped
architecture** using the actual `mapped.json` cell inventory. It preserves the
existing `MSIF_CELL_MODELS` path as an explicitly validated baseline dependency,
records hashes for the generated exact bundle, and fails if any mapped wrapper
is absent or if preprocessing fails. The functional bundle is generated under
`build/m71_liberty/m71_lq/` and is **not committed**.

On Node1:
